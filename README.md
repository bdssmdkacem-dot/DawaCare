# DawaCare — Personal planner branch

هذه branch تجريبية مستقلة هدفها اختبار مسار **Personal account** في Google Play
من خلال إزالة وظائف إدارة الأدوية والرعاية الصحية من تجربة التطبيق المنشورة،
مع الحفاظ على أكبر قدر ممكن من البنية الحالية.

## نطاق هذه branch

تمت إعادة توجيه التطبيق إلى:

- تسجيل الدخول والحساب الشخصي.
- الملف الشخصي والإعدادات واللغة.
- تذكيرات يومية عامة للمستخدم، مثل الدراسة والرياضة والمكالمات والمهام.
- إشعارات محلية مجدولة لهذه التذكيرات.
- الإعلانات الموجودة أصلًا.

تمت إزالة الوصول من واجهة التطبيق إلى:

- إدارة الأدوية.
- الجداول والجرعات.
- تتبع الالتزام بالجرعات.
- تنبيهات المرافق المرتبطة بالجرعات.
- شاشات المريض/المرافق الصحية.
- الرسائل المرتبطة بجرعات أو مرضى.

## لماذا؟

سياسة Google الحالية تشترط حساب Organization للتطبيقات الصحية، وتذكر
صراحةً أن **Medication and Treatment Management** تشمل إدارة جداول الأدوية،
التذكيرات الدوائية وإدارة الوصفات.

لذلك لا نغيّر تصريح Health Apps إلى "لا توجد ميزات صحية" مع إبقاء الوظائف
الصحية متاحة للمستخدم. هذه branch تختبر تغييرًا فعليًا في الوظيفة المعروضة.

## ملاحظات

الكود القديم الخاص بنظام الأدوية ما زال موجودًا في المستودع في هذه المرحلة
حتى نستطيع الرجوع إليه بسهولة، لكنه لم يعد مستوردًا من مسار تشغيل التطبيق
في هذه branch. الخطوة التالية بعد نجاح CI هي تنظيف الملفات غير المستخدمة
والاختبارات/المخططات القديمة بشكل منفصل، ثم مراجعة Play Console قبل أي إرسال
للمراجعة.

## التشغيل

استخدم GitHub Actions للبناء والاختبار كما في الفرع الرئيسي. لا يتم دمج هذه
branch في `main` تلقائيًا.
