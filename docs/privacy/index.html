سياسة الخصوصية — DawaCare

توضح هذه السياسة كيف يعالج تطبيق DawaCare البيانات عند استخدامه. في هذه النسخة، التطبيق عبارة عن مخطط شخصي وتذكيرات يومية عامة، ولا يوفر إدارة أدوية أو تتبع جرعات أو رعاية صحية.

1. البيانات التي نعالجها

  • بيانات الحساب والملف الشخصي مثل الاسم والبريد الإلكتروني ورقم الهاتف عند توفيره.
  • التذكيرات اليومية التي ينشئها المستخدم ووقت التذكير.
  • صورة الملف الشخصي إذا اختار المستخدم رفعها.
  • بيانات تقنية ضرورية لتشغيل الحساب والخدمات.

2. الاستخدام

نستخدم البيانات لتوفير الحساب، حفظ الملف الشخصي، حفظ التذكيرات اليومية، إرسال الإشعارات التي يطلبها المستخدم، وتشغيل التطبيق وخدماته.

3. مزودو الخدمات

يستخدم التطبيق Supabase للمصادقة وقاعدة البيانات والتخزين اللازم للخدمة، كما قد يستخدم مزودي الإعلانات لتقديم الإعلانات داخل التطبيق وفق إعدادات تلك الخدمات.

4. الاحتفاظ والحذف

تُحتفظ البيانات طالما كان الحساب نشطًا أو طالما كانت ضرورية لتقديم الخدمة. يمكن طلب حذف الحساب والبيانات المرتبطة به عبر صفحة التواصل في مستودع DawaCare على GitHub.

5. الأمان

تُنقل البيانات عبر اتصالات مشفرة، وتستخدم ضوابط وصول مناسبة لحماية بيانات الحساب.

6. الأطفال

التطبيق ليس موجهًا للأطفال دون السن المسموح به قانونيًا.

7. التواصل

المطور: Abdessamad Kassim.

Politique de confidentialité — DawaCare

Cette politique explique comment DawaCare traite les données. Dans cette version, l'application est un agenda personnel avec des rappels quotidiens généraux et ne fournit pas de gestion des médicaments, de suivi des doses ni de services de soins de santé.

1. Données traitées

  • Données du compte et du profil telles que le nom, l'e-mail et le téléphone lorsqu'ils sont fournis.
  • Rappels quotidiens créés par l'utilisateur et leurs horaires.
  • Photo de profil si l'utilisateur choisit d'en importer une.
  • Données techniques nécessaires au fonctionnement du compte et du service.

2. Utilisation

Les données servent à fournir le compte, le profil, les rappels quotidiens, les notifications demandées par l'utilisateur et le fonctionnement général de l'application.

3. Prestataires

L'application utilise Supabase pour l'authentification, la base de données et le stockage nécessaire au service, ainsi que, le cas échéant, des fournisseurs publicitaires pour afficher les annonces conformément à leurs propres paramètres.

4. Conservation et suppression

Les données sont conservées tant que le compte est actif ou aussi longtemps que nécessaire pour fournir le service. Une demande de suppression peut être envoyée via le dépôt GitHub de DawaCare.

5. Sécurité

Les données sont transmises via des connexions chiffrées et des contrôles d'accès appropriés protègent les données du compte.

6. Enfants

L'application n'est pas destinée aux enfants en dessous de l'âge légal applicable.

7. Contact

Développeur : Abdessamad Kassim.

Privacy Policy — DawaCare

This policy explains how DawaCare processes data. In this version, the app is a personal planner with general daily reminders and does not provide medication management, dose tracking, or healthcare services.

1. Data we process

  • Account and profile data such as name, email address, and phone number when provided.
  • Daily reminders created by the user and their scheduled times.
  • Profile photo if the user chooses to upload one.
  • Technical data necessary to operate the account and service.

2. How we use data

Data is used to provide the account, profile, daily reminders, user-requested notifications, and general operation of the application.

3. Service providers

The app uses Supabase for authentication, database services, and required storage, and may use advertising providers to display ads in accordance with their service settings.

4. Retention and deletion

Data is retained while an account is active or as necessary to provide the service. Users can request account and associated data deletion through the DawaCare GitHub repository.

5. Security

Data is transmitted using encrypted connections and appropriate access controls are used to protect account data.

6. Children

The application is not directed at children below the applicable legal age.

7. Contact

Developer: Abdessamad Kassim.
